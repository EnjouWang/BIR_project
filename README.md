## Biomedical Information Retrieval Project #2
### 一、系統概要
本系統以先前建立的文獻搜尋系統為基礎，進一步加入語言統計分析與搜尋改良功能，針對搜尋準確度與文字統計分析能力的能力提升。
### 二、Zipf 分佈分析功能 
計算字詞在所有上傳文件中的頻率分佈，並以動態圖表呈現Zipf Distribution。
1.	資料統計：將所有上傳 XML 內的標題與摘要文字合併，計算每個字詞的出現頻率，並依照頻率由高到低排序，最後計算 rank 與 normalized frequency。
2.	詞幹化處理（Stemming）：採用 Porter Algorithm 對詞彙進行詞幹化，將字形變化（如 “cancers”、“cancerous”）歸為同一詞根 “cancer”，繪圖並比較原始版本與詞幹化版本的 Zipf 分佈差異。
3.	結果視覺化：提供Frequency和Normalized Frequency兩種顯示模式，可在滑鼠懸停時顯示對應的單字與頻率資訊。在 log-log scale 上整體趨勢呈現近似線性關係，詞幹化版本曲線稍微平滑且略高於原始曲線，因為詞幹化後詞的種類變少、詞頻總數集中。
### 三、Edit Distance 模糊搜尋功能
系統新增了模糊搜尋功能，能在輸入錯誤時自動尋找相似詞進行比對。
1.	Edit Distance：採用動態規劃（Dynamic Programming）實作，若輸入詞與某候選詞的距離小於閾值（如 ≤2），則視為相似詞。
2.	搜尋流程：使用者輸入查詢詞後，若未找到結果，則以 Edit Distance 在資料庫內所有詞彙中尋找距離最接近者。系統將以最相近的詞（如將「cancr」修正為「cancer」）重新搜尋，並於頁面上提示「顯示與 cancr 相近的搜尋結果（最接近詞：cancer）」。
3.	結果顯示： 搜尋結果同時根據相似詞的出現次數重新排序，確保相關度最高的文章優先顯示。
### 四、系統功能特色與擴充
1.	新增搜尋結果排序功能：以每篇文章中關鍵字出現的次數（title + abstract）作為排序依據，讓關鍵字出現較多的文章排名更前。若啟用模糊搜尋，排序也會根據實際相似詞的出現次數重新調整。
2.	支援同時上傳多個 XML 檔案：系統會自動逐一解析每個檔案內容並匯入資料庫。
3.	搜尋的篩選功能：搜尋時可設定年份與期刊名稱進行篩選，而且選項會自動列出已上傳文件中年份與期刊的集合。
4.	Zipf 互動式圖表呈現：滑鼠懸停時會顯示 rank、word 與 frequency 資訊，並且支援放大、縮小與下載圖片的功能。
5.	新增回到頂端按鈕：為了提升頁面的使用便利性，在搜尋結果與檔案上傳頁面底部新增此按鈕，方便使用者回到頁面頂端進行其他操作。
